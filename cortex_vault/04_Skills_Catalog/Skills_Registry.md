# ⚡ Autopoietic Procedural Skills Registry

The `AutopoieticSkillCrystallizer` synthesizes, tests, and crystallizes self-contained procedural skills in `cortex/skills/`.

## Active Skills
1. **`skill_file_auditor`**: Scans the workspace git tree and reports modified, untracked, and clean files.
2. **`skill_system_telemetry`**: Gathers CPU, RAM, GPU, and process metrics.
3. **`skill_media_controller`**: Interacts with Windows Media Control subsystem.
4. **`skill_shadow_checkpoint`**: Creates and restores git shadow rollback checkpoints.
5. **`skill_vault_sync`**: Synchronizes Obsidian Vault to the private backup repository.
